# Test rendering font

`Roboto.ttf` is the unmodified variable Roboto font from
[Google Fonts](https://github.com/google/fonts/tree/main/ofl/roboto), licensed under
SIL Open Font License 1.1 (see `OFL.txt`). It is used only by the optional
Flutter-rendered CI previews, not bundled into the app. Keeping it in the test
fixture makes previews independent of a CI worker's installed fonts.
