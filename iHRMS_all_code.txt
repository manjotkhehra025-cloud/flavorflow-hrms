# iHRMS – Employee Self-Service HR App (Flutter starter)

iHRMS is a company HR app in the style of HROne. It is a **starter project**: every screen works,
using sample (mock) data stored in memory. Next you connect a real backend (Firebase or your own API).

* Flutter 3 / Dart 3 (null-safe), Material 3, blue theme, amounts in INR (₹)
* State management: `provider`
* Data layer: repository interfaces plus mock implementations, so a real backend plugs in later
* Platforms: Android, iOS, Web

Verified on Flutter 3.47.8 (Dart 3.13): `flutter analyze` reports no issues, `flutter test` passes
(this includes a smoke test that opens every screen), and `flutter build web` succeeds.

## Features

| Area | What works now |
|------|----------------|
| Splash and login | Employee ID and password, mock authentication, employee or admin role |
| Dashboard | Greeting, live clock, today's punch status, quick-action tiles, leave balance, last salary, next holiday, latest announcement |
| Attendance | Punch in and punch out with time and hours worked, a monthly calendar coloured by status, monthly summary, day-by-day history |
| Leave | Balance cards (CL, SL, EL), apply with type, date range and reason (Sundays are not counted), status list, cancel a pending request |
| Payslips | List of months, detail view with earnings, deductions and net pay (PF, ESI, Professional Tax, TDS), a "Download PDF" stub |
| Holidays | Yearly list with the next holiday highlighted |
| Announcements | List with pinned items; admins can post and delete |
| Profile | Work and personal details, change password, logout |
| Admin | Employee list with search, add and edit an employee (role, salary, active), leave approvals (approve or reject with a comment), daily attendance report |

## Connecting a real backend

The screens and providers only use the abstract repositories in `lib/repositories/`.
To go live:

1. Create implementations, for example `lib/repositories/firebase/firebase_auth_repository.dart`
   containing `class FirebaseAuthRepository implements AuthRepository`. Do the same for
   Employee, Attendance, Leave, Payslip and Content.
2. Return them from `buildRepositories()` in `lib/repositories/repository_factory.dart`.
3. No screen or provider has to change.

Suggested Firebase layout:

* **Auth:** Firebase Auth. Map the employee ID to an email such as `emp001@yourcompany.com`, or use a Cloud Function.
* **Firestore collections:**
  * `employees/{id}`: profile fields plus `role` (`employee` or `admin`)
  * `attendance/{employeeId}_{yyyy-MM-dd}`: punchIn, punchOut, location, selfieUrl
  * `leaves/{id}`: employeeId, type, fromDate, toDate, reason, status, approverComment
  * `payslips/{id}`: employeeId, month, earnings[], deductions[]
  * `holidays/{id}` and `announcements/{id}`
* Add security rules so employees can read and write only their own data and admins can access everything.

Do not put real API keys or passwords in the code. Use `flutterfire configure`, which generates `firebase_options.dart`.

/// Wires every repository and provider into the widget tree.
class AppProviders extends StatelessWidget {
  const AppProviders({super.key, required this.repositories, required this.child});
  final Repositories repositories;
  final Widget child;

  @override
  Widget build(BuildContext context) {
    final repos = repositories;
    return MultiProvider(
      providers: [
        Provider<Repositories>.value(value: repos),
        ChangeNotifierProvider(create: (_) => AuthProvider(repos.auth)),
        ChangeNotifierProvider(create: (_) => AttendanceProvider(repos.attendance)),
        ChangeNotifierProvider(create: (_) => LeaveProvider(repos.leave)),
        ChangeNotifierProvider(create: (_) => PayslipProvider(repos.payslips)),
        ChangeNotifierProvider(create: (_) => EmployeeProvider(repos.employees)),
        ChangeNotifierProvider(create: (_) => ContentProvider(repos.content)),
      ],
      child: child,
    );
  }
}

/// Formatting helpers (INR currency, dates, times).
class Fmt {
  Fmt._();

  static final NumberFormat _inr =
      NumberFormat.currency(locale: 'en_IN', symbol: '\u20B9', decimalDigits: 0);
  static final NumberFormat _inr2 =
      NumberFormat.currency(locale: 'en_IN', symbol: '\u20B9', decimalDigits: 2);

  /// e.g. 1,25,000 -> "\u20B91,25,000"
  static String inr(num value) => _inr.format(value);
  static String inrPrecise(num value) => _inr2.format(value);

  static String date(DateTime d) => DateFormat('dd MMM yyyy').format(d);
  static String shortDate(DateTime d) => DateFormat('dd MMM').format(d);
  static String weekday(DateTime d) => DateFormat('EEE').format(d);
  static String fullDay(DateTime d) => DateFormat('EEEE, dd MMM yyyy').format(d);
  static String month(DateTime d) => DateFormat('MMMM yyyy').format(d);
  static String time(DateTime? d) =>
      d == null ? '--:--' : DateFormat('hh:mm a').format(d);

  static String duration(Duration d) {
    final h = d.inHours;
    final m = d.inMinutes.remainder(60).toString().padLeft(2, '0');
    return '${h}h ${m}m';
  }
}

class AttendanceRecord {
  const AttendanceRecord({
    required this.employeeId,
    required this.date,
    required this.status,
    this.punchIn,
    this.punchOut,
    this.punchInLocation,
    this.punchOutLocation,
    this.selfieUrl,
    this.note,
  });

  final String employeeId;

  /// The calendar day (time part is ignored).
  final DateTime date;
  final AttendanceStatus status;
  final DateTime? punchIn;
  final DateTime? punchOut;
  final PunchLocation? punchInLocation;
  final PunchLocation? punchOutLocation;

  /// TODO(selfie): URL/path of the selfie captured at punch-in.
  final String? selfieUrl;
  final String? note;

  bool get hasPunchedIn => punchIn != null;
  bool get hasPunchedOut => punchOut != null;
  bool get isWorking => punchIn != null && punchOut == null;

  Duration get workedDuration {
    if (punchIn == null) return Duration.zero;
    final end = punchOut ?? DateTime.now();
    final d = end.difference(punchIn!);
    return d.isNegative ? Duration.zero : d;
  }

  AttendanceRecord copyWith({
    AttendanceStatus? status,
    DateTime? punchIn,
    DateTime? punchOut,
    PunchLocation? punchInLocation,
    PunchLocation? punchOutLocation,
    String? selfieUrl,
    String? note,
  }) {
    return AttendanceRecord(
      employeeId: employeeId,
      date: date,
      status: status ?? this.status,
      punchIn: punchIn ?? this.punchIn,
      punchOut: punchOut ?? this.punchOut,
      punchInLocation: punchInLocation ?? this.punchInLocation,
      punchOutLocation: punchOutLocation ?? this.punchOutLocation,
      selfieUrl: selfieUrl ?? this.selfieUrl,
      note: note ?? this.note,
    );
  }
}

  const Employee({
    required this.id,
    required this.name,

    required this.phone,
    required this.department,
    required this.designation,
    required this.joiningDate,
    required this.monthlyCtc,

    this.managerName,
    this.address,
    this.bloodGroup,

  /// Employee code used to log in, e.g. EMP001.
  final String id;
  final String name;
  final String email;
  final String phone;
  final String department;
  final String designation;
  final DateTime joiningDate;

  /// Monthly gross salary in INR (used by the mock payslip generator).
  final double monthlyCtc;
  final UserRole role;
  final String? managerName;
  final String? address;
  final String? bloodGroup;
  final bool isActive;

  bool get isAdmin => role == UserRole.admin;

  String get firstName => name.split(' ').first;

    final parts = name.trim().split(RegExp(r'\s+'));

    return (parts.first[0] + parts.last[0]).toUpperCase();

    String? email,
    String? phone,

    String? designation,

class LeaveRequest {
  const LeaveRequest({
    required this.id,
    required this.employeeId,
    required this.employeeName,
    required this.type,
    required this.fromDate,
    required this.toDate,
    required this.reason,
    required this.appliedOn,
    this.status = LeaveStatus.pending,
    this.approverComment,
  });

  final String id;
  final String employeeId;
  final String employeeName;
  final LeaveType type;
  final DateTime fromDate;
  final DateTime toDate;
  final String reason;
  final DateTime appliedOn;
  final LeaveStatus status;
  final String? approverComment;

  /// Number of leave days (Sundays are not counted).
  int get days => countLeaveDays(fromDate, toDate);

  bool covers(DateTime day) {
    final d = DateTime(day.year, day.month, day.day);
    final from = DateTime(fromDate.year, fromDate.month, fromDate.day);
    final to = DateTime(toDate.year, toDate.month, toDate.day);
    return !d.isBefore(from) && !d.isAfter(to);
  }

  LeaveRequest copyWith({LeaveStatus? status, String? approverComment}) {
    return LeaveRequest(
      id: id,
      employeeId: employeeId,
      employeeName: employeeName,
      type: type,
      fromDate: fromDate,
      toDate: toDate,
      reason: reason,
      appliedOn: appliedOn,
      status: status ?? this.status,
      approverComment: approverComment ?? this.approverComment,
    );
  }
}

int countLeaveDays(DateTime from, DateTime to) {
  var d = DateTime(from.year, from.month, from.day);
  final end = DateTime(to.year, to.month, to.day);
  var count = 0;
  while (!d.isAfter(end)) {
    if (d.weekday != DateTime.sunday) count++;
    d = DateTime(d.year, d.month, d.day + 1);
  }
  return count;
}

  List<AttendanceRecord> get monthRecords => _month;

  bool get punching => _punching;

  bool get isCurrentMonth {
    final now = DateTime.now();
    return _selectedMonth.year == now.year && _selectedMonth.month == now.month;
  }

  Map<AttendanceStatus, int> get monthSummary {
    final map = <AttendanceStatus, int>{};
    for (final r in _month) {
      map[r.status] = (map[r.status] ?? 0) + 1;

  }

      _month.fold(Duration.zero, (sum, r) => sum + r.workedDuration);

      _month = await _repo.getMonth(employeeId, _selectedMonth.year, _selectedMonth.month);
    } finally {
      _loading = false;
      notifyListeners();
    }
  }

  Future<void> changeMonth(int delta) async {
    final next = DateTime(_selectedMonth.year, _selectedMonth.month + delta);
    final now = DateTime.now();
    if (next.isAfter(DateTime(now.year, now.month))) return;
    _selectedMonth = next;
    final id = _employeeId;
    if (id != null) await load(id);
  }

  /// Punches in, or out if already punched in. Returns an error message or null.
  Future<String?> punch() async {
    final id = _employeeId;
    if (id == null) return 'Not logged in';
    _punching = true;
    notifyListeners();
    try {
      // --- Location / geo-fence hook -------------------------------------
      final location = await _verification.getCurrentLocation();
      if (!_verification.isInsideOffice(location)) {
        return 'You are outside the office area. Punch not allowed.';
      }
      if (_today == null || !_today!.hasPunchedIn) {
        // --- Selfie hook ---------------------------------------------------
        final selfie = await _verification.captureSelfie();
        _today = await _repo.punchIn(id, location: location, selfieUrl: selfie);
      } else if (!_today!.hasPunchedOut) {
        _today = await _repo.punchOut(id, location: location);
      } else {
        return 'You have already completed today\'s attendance';
      }
      if (isCurrentMonth) {
        _month = await _repo.getMonth(id, _selectedMonth.year, _selectedMonth.month);
      }
      return null;
    } on AppException catch (e) {
      return e.message;
    } finally {
      _punching = false;
      notifyListeners();
    }
  }

  void clear() {
    _employeeId = null;
    _today = null;
    _month = [];
    _selectedMonth = DateTime(DateTime.now().year, DateTime.now().month);
  }

class MockLeaveRepository implements LeaveRepository {
  MockLeaveRepository(this._db);
  final MockDatabase _db;
  int _seq = 100;

  @override
  Future<List<LeaveBalance>> getBalances(String employeeId) async {
    await MockDatabase.latency(150);
    final year = DateTime.now().year;
    return MockDatabase.leaveQuota.entries.map((q) {
      double used = 0, pending = 0;
      for (final l in _db.leaves) {
        if (l.employeeId != employeeId || l.type != q.key || l.fromDate.year != year) continue;
        if (l.status == LeaveStatus.approved) used += l.days;
        if (l.status == LeaveStatus.pending) pending += l.days;
      }
      return LeaveBalance(type: q.key, total: q.value, used: used, pending: pending);
    }).toList();
  }

  @override
  Future<List<LeaveRequest>> getMyRequests(String employeeId) async {
    await MockDatabase.latency();
    final list = _db.leaves.where((l) => l.employeeId == employeeId).toList();
    list.sort((a, b) => b.appliedOn.compareTo(a.appliedOn));
    return list;
  }

  @override
  Future<List<LeaveRequest>> getAllRequests({bool pendingOnly = false}) async {
    await MockDatabase.latency();
    final list = _db.leaves.where((l) => !pendingOnly || l.status == LeaveStatus.pending).toList();
    list.sort((a, b) => b.appliedOn.compareTo(a.appliedOn));
    return list;
  }

  @override
  Future<LeaveRequest> apply({
    required String employeeId,
    required String employeeName,
    required LeaveType type,
    required DateTime fromDate,
    required DateTime toDate,
    required String reason,
  }) async {
    await MockDatabase.latency(400);
    final from = dateOnly(fromDate);
    final to = dateOnly(toDate);
    if (to.isBefore(from)) throw const AppException('End date cannot be before start date');
    final days = countLeaveDays(from, to);
    if (days == 0) throw const AppException('Selected dates fall on week-offs only');
    if (reason.trim().isEmpty) throw const AppException('Please enter a reason');

    for (final l in _db.leaves) {
      if (l.employeeId != employeeId) continue;
      if (l.status != LeaveStatus.pending && l.status != LeaveStatus.approved) continue;
      final overlaps = !(to.isBefore(dateOnly(l.fromDate)) || from.isAfter(dateOnly(l.toDate)));
      if (overlaps) throw const AppException('You already have a leave request for these dates');
    }

    if (type.hasQuota) {
      final balances = await getBalances(employeeId);
      final b = balances.firstWhere((x) => x.type == type);
      final free = b.available - b.pending;
      if (days > free) {
        throw AppException('Not enough ${type.label} balance (available: ${free.toStringAsFixed(0)} days)');
      }
    }

    final request = LeaveRequest(
      id: 'L${_seq++}',
      employeeId: employeeId,
      employeeName: employeeName,
      type: type,
      fromDate: from,
      toDate: to,
      reason: reason.trim(),
      appliedOn: DateTime.now(),
    );
    _db.leaves.add(request);
    return request;
  }

  @override
  Future<LeaveRequest> cancel(String requestId) async {
    await MockDatabase.latency();
    final i = _db.leaves.indexWhere((l) => l.id == requestId);
    if (i < 0) throw const AppException('Leave request not found');
    if (_db.leaves[i].status != LeaveStatus.pending) {
      throw const AppException('Only pending requests can be cancelled');
    }
    _db.leaves[i] = _db.leaves[i].copyWith(status: LeaveStatus.cancelled);
    return _db.leaves[i];
  }

  @override
  Future<LeaveRequest> updateStatus(String requestId, LeaveStatus status, {String? comment}) async {
    await MockDatabase.latency();
    final i = _db.leaves.indexWhere((l) => l.id == requestId);

  }

/// Generates realistic sample payslips from each employee's monthly CTC.
/// Indian structure: Basic, HRA, Conveyance, Special Allowance;
/// deductions: PF (12% of basic, capped), ESI (0.75% if gross <= 21,000),
/// Professional Tax and TDS.
class MockPayslipRepository implements PayslipRepository {
  MockPayslipRepository(this._db);
  final MockDatabase _db;

  @override
  Future<List<Payslip>> getPayslips(String employeeId) async {
    await MockDatabase.latency();
    final employee = _db.employee(employeeId);
    if (employee == null) return [];
    final now = DateTime.now();
    final slips = <Payslip>[];
    for (var i = 1; i <= 6; i++) {
      final month = DateTime(now.year, now.month - i, 1);
      if (month.isBefore(DateTime(employee.joiningDate.year, employee.joiningDate.month, 1))) break;
      slips.add(_build(employeeId, employee.monthlyCtc, month));
    }
    return slips;
  }

  Payslip _build(String employeeId, double gross, DateTime month) {
    final basic = (gross * 0.5).roundToDouble();
    final hra = (gross * 0.2).roundToDouble();
    const conveyance = 1600.0;
    final special = (gross - basic - hra - conveyance).clamp(0, gross).toDouble();

    final pf = (basic * 0.12).clamp(0, 1800).roundToDouble();
    final esi = gross <= 21000 ? (gross * 0.0075).ceilToDouble() : 0.0;
    const pt = 200.0;
    final tds = gross > 60000 ? ((gross - 60000) * 0.1).roundToDouble() : 0.0;

    final daysInMonth = DateTime(month.year, month.month + 1, 0).day;
    return Payslip(
      id: '$employeeId-${month.year}-${month.month}',
      employeeId: employeeId,
      month: month,
      workingDays: daysInMonth,
      paidDays: daysInMonth.toDouble(),
      bankAccountMasked: 'XXXX XXXX 4321',
      earnings: [
        PayItem('Basic Salary', basic),
        PayItem('House Rent Allowance', hra),
        const PayItem('Conveyance Allowance', conveyance),
        PayItem('Special Allowance', special),
      ],
      deductions: [
        PayItem('Provident Fund (PF)', pf),
        if (esi > 0) PayItem('ESI', esi),
        const PayItem('Professional Tax', pt),
        if (tds > 0) PayItem('Income Tax (TDS)', tds),
      ],
    );
  }

class _MonthCalendar extends StatelessWidget {
  const _MonthCalendar({required this.month, required this.records});
  final DateTime month;
  final List<AttendanceRecord> records;

  @override
  Widget build(BuildContext context) {
    final daysInMonth = DateTime(month.year, month.month + 1, 0).day;
    final leading = DateTime(month.year, month.month, 1).weekday - 1; // Monday first
    final byDay = {for (final r in records) r.date.day: r};
    const weekdays = ['M', 'T', 'W', 'T', 'F', 'S', 'S'];
    final cells = <Widget>[
      ...weekdays.map((d) => Center(child: Text(d, style: const TextStyle(fontWeight: FontWeight.w600, color: AppTheme.muted)))),
      ...List.generate(leading, (_) => const SizedBox()),
      ...List.generate(daysInMonth, (i) {
        final day = i + 1;
        final r = byDay[day];
        final color = r == null ? null : attendanceColor(r.status);
        final isToday = isSameDay(DateTime(month.year, month.month, day), DateTime.now());
        return Container(
          margin: const EdgeInsets.all(3),
          decoration: BoxDecoration(
            color: color?.withValues(alpha: 0.15),
            borderRadius: BorderRadius.circular(8),
            border: isToday ? Border.all(color: AppTheme.primary, width: 2) : null,
          ),
          alignment: Alignment.center,
          child: Text(
            '$day',
            style: TextStyle(color: color ?? Colors.grey.shade400, fontWeight: FontWeight.w600),
          ),
        );
      }),
    ];
    return GridView.count(
      crossAxisCount: 7,
      shrinkWrap: true,
      physics: const NeverScrollableScrollPhysics(),
      children: cells,
    );
  }

class HomeShell extends StatefulWidget {
  const HomeShell({super.key});

  /// Lets child screens switch tabs, e.g. HomeShell.of(context)?.goTo(1).
  static HomeShellState? of(BuildContext context) => context.findAncestorStateOfType<HomeShellState>();

  @override
  State<HomeShell> createState() => HomeShellState();
}

class HomeShellState extends State<HomeShell> {
  int _index = 0;

  static const tabAttendance = 1;
  static const tabLeave = 2;
  static const tabPayslip = 3;

  @override
  void initState() {
    super.initState();
    WidgetsBinding.instance.addPostFrameCallback((_) => refreshAll());
  }

  Future<void> refreshAll() async {
    final user = context.read<AuthProvider>().user;
    if (user == null) return;
    final futures = <Future<void>>[
      context.read<AttendanceProvider>().load(user.id),
      context.read<LeaveProvider>().loadMine(user.id),
      context.read<PayslipProvider>().load(user.id),
      context.read<ContentProvider>().load(),
    ];
    if (user.isAdmin) {
      futures.add(context.read<EmployeeProvider>().load());
      futures.add(context.read<LeaveProvider>().loadAll());
    }
    await Future.wait(futures);
  }

  void goTo(int index) => setState(() => _index = index);

  @override
  Widget build(BuildContext context) {
    final pages = const [
      DashboardScreen(),
      AttendanceScreen(),
      LeaveScreen(),
      PayslipListScreen(),
      MoreScreen(),
    ];
    return Scaffold(
      body: IndexedStack(index: _index, children: pages),
      bottomNavigationBar: NavigationBar(
        selectedIndex: _index,

          NavigationDestination(icon: Icon(Icons.home_outlined), selectedIcon: Icon(Icons.home), label: 'Home'),

    final picked = await showDateRangePicker(
      context: context,
      firstDate: DateTime(now.year, now.month - 1, 1),
      lastDate: DateTime(now.year + 1, 12, 31),
      initialDateRange: _range,
      helpText: 'Select leave dates',
    );

            else if (leave.myRequests.isEmpty)
              const EmptyState(icon: Icons.event_available, message: 'No leave requests yet')
            else
              ...leave.myRequests.map((r) => LeaveRequestTile(request: r, onCancel: () => _cancel(context, r))),
          ],
        ),
      ),
    );
  }

  Future<void> _cancel(BuildContext context, LeaveRequest r) async {
    final ok = await showDialog<bool>(
      context: context,
      builder: (ctx) => AlertDialog(
        title: const Text('Cancel leave request?'),
        content: Text('${r.type.label}: ${Fmt.shortDate(r.fromDate)} - ${Fmt.shortDate(r.toDate)}'),
        actions: [
          TextButton(onPressed: () => Navigator.pop(ctx, false), child: const Text('No')),
          FilledButton(onPressed: () => Navigator.pop(ctx, true), child: const Text('Yes, cancel')),
        ],
      ),
    );
    if (ok != true || !context.mounted) return;
    final error = await context.read<LeaveProvider>().cancel(r);
    if (!context.mounted) return;
    showSnack(context, error ?? 'Leave request cancelled', error: error != null);
  }
}

/// Today's punch in / punch out card with a live clock.
class PunchCard extends StatefulWidget {
  const PunchCard({super.key});

  @override
  State<PunchCard> createState() => _PunchCardState();
}

class _PunchCardState extends State<PunchCard> {
  late Timer _timer;
  DateTime _now = DateTime.now();

  @override
  void initState() {
    super.initState();
    _timer = Timer.periodic(const Duration(seconds: 1), (_) {
      if (mounted) setState(() => _now = DateTime.now());
    });
  }

  @override
  void dispose() {
    _timer.cancel();
    super.dispose();
  }

  Future<void> _punch() async {
    final provider = context.read<AttendanceProvider>();
    final wasIn = provider.today?.hasPunchedIn ?? false;
    final error = await provider.punch();
    if (!mounted) return;
    if (error != null) {
      showSnack(context, error, error: true);
    } else {
      showSnack(context, wasIn ? 'Punched out at ${Fmt.time(DateTime.now())}' : 'Punched in at ${Fmt.time(DateTime.now())}');
    }
  }

  @override
  Widget build(BuildContext context) {
    final provider = context.watch<AttendanceProvider>();
    final today = provider.today;
    final isOff = today != null &&
        (today.status == AttendanceStatus.holiday ||
            today.status == AttendanceStatus.weekend ||
            today.status == AttendanceStatus.leave) &&
        !today.hasPunchedIn;
    final done = today?.hasPunchedOut ?? false;
    final working = today?.isWorking ?? false;

    String statusText;
    if (today == null) {
      statusText = 'Loading...';
    } else if (done) {
      statusText = 'Day complete';
    } else if (working) {
      statusText = 'You are punched in';
    } else if (isOff) {
      statusText = today.note ?? today.status.label;
    } else {
      statusText = 'Not punched in yet';
    }

    return Container(
      padding: const EdgeInsets.all(18),
      decoration: BoxDecoration(
        gradient: const LinearGradient(
          colors: [AppTheme.primary, AppTheme.primaryDark],
          begin: Alignment.topLeft,
          end: Alignment.bottomRight,
        ),
        borderRadius: BorderRadius.circular(18),
      ),
      child: Column(
        crossAxisAlignment: CrossAxisAlignment.start,
        children: [
          Row(
            children: [
              Expanded(
                child: Column(
                  crossAxisAlignment: CrossAxisAlignment.start,
                  children: [
                    Text(Fmt.fullDay(_now), style: const TextStyle(color: Colors.white70, fontSize: 13)),
                    const SizedBox(height: 4),
                    Text(Fmt.time(_now), style: const TextStyle(color: Colors.white, fontSize: 30, fontWeight: FontWeight.bold)),
                  ],
                ),
              ),
              Container(
                padding: const EdgeInsets.symmetric(horizontal: 10, vertical: 6),
                decoration: BoxDecoration(
                  color: Colors.white.withValues(alpha: 0.18),
                  borderRadius: BorderRadius.circular(20),
                ),
                child: Text(statusText, style: const TextStyle(color: Colors.white, fontSize: 12, fontWeight: FontWeight.w600)),
              ),
            ],
          ),
          const SizedBox(height: 16),
          Row(
            children: [
              _timeBox('Punch In', Fmt.time(today?.punchIn)),
              const SizedBox(width: 10),
              _timeBox('Punch Out', Fmt.time(today?.punchOut)),
              const SizedBox(width: 10),
              _timeBox('Worked', today?.hasPunchedIn == true ? Fmt.duration(today!.workedDuration) : '--'),
            ],
          ),
          const SizedBox(height: 16),
          SizedBox(
            width: double.infinity,
            child: FilledButton.icon(
              style: FilledButton.styleFrom(
                backgroundColor: Colors.white,
                foregroundColor: working ? AppTheme.danger : AppTheme.primary,
                disabledBackgroundColor: Colors.white.withValues(alpha: 0.4),
              ),
              onPressed: (today == null || done || provider.punching) ? null : _punch,
              icon: provider.punching
                  ? const SizedBox(width: 18, height: 18, child: CircularProgressIndicator(strokeWidth: 2))
                  : Icon(working ? Icons.logout : Icons.fingerprint),
              label: Text(
                done ? 'Attendance marked' : (working ? 'Punch Out' : 'Punch In'),
                style: const TextStyle(fontWeight: FontWeight.bold, fontSize: 16),
              ),
            ),
          ),
        ],
      ),
    );
  }

  Widget _timeBox(String label, String value) {
    return Expanded(
      child: Container(
        padding: const EdgeInsets.symmetric(vertical: 10, horizontal: 8),
        decoration: BoxDecoration(
          color: Colors.white.withValues(alpha: 0.12),
          borderRadius: BorderRadius.circular(12),
        ),
        child: Column(
          children: [
            Text(label, style: const TextStyle(color: Colors.white70, fontSize: 11)),
            const SizedBox(height: 4),
            FittedBox(
              child: Text(value, style: const TextStyle(color: Colors.white, fontWeight: FontWeight.bold, fontSize: 14)),
            ),
          ],
        ),
      ),
    );
  }
}

/// Opens every screen on a phone-sized display and fails on any
/// layout overflow or exception.
void main() {
  Future<void> settle(WidgetTester tester, [int steps = 10]) async {
    for (var i = 0; i < steps; i++) {
      await tester.pump(const Duration(milliseconds: 200));
    }
  }

  Future<void> login(WidgetTester tester, String id, String pw) async {
    tester.view.physicalSize = const Size(1170, 2532);
    tester.view.devicePixelRatio = 3;
    addTearDown(tester.view.reset);
    await tester.pumpWidget(AppProviders(repositories: buildRepositories(), child: const IhrmsApp()));
    await settle(tester, 12); // splash
    expect(find.text('Welcome to iHRMS'), findsOneWidget);
    await tester.enterText(find.byType(TextFormField).at(0), id);
    await tester.enterText(find.byType(TextFormField).at(1), pw);
    await tester.tap(find.text('Login'));
    await settle(tester, 12);
  }

  Future<void> openAndBack(WidgetTester tester, Finder finder) async {
    await tester.ensureVisible(finder);
    await tester.tap(finder);
    await settle(tester);
    await tester.pageBack();
    await settle(tester, 4);
  }

  Future<void> tab(WidgetTester tester, IconData icon) async {
    await tester.tap(find.descendant(of: find.byType(NavigationBar), matching: find.byIcon(icon)));
    await settle(tester);
  }

  testWidgets('employee flow', (tester) async {
    await login(tester, 'EMP001', 'emp123');
    expect(find.text('Manjot'), findsOneWidget);

    final punch = find.text('Punch In');

      await tester.tap(punch.first);
      await settle(tester);

    await tab(tester, Icons.access_time);

    await tester.tap(find.byIcon(Icons.chevron_left).hitTestable().first);
    await settle(tester);
    await tester.scrollUntilVisible(find.text('History'), 300, scrollable: find.byType(Scrollable).hitTestable().first);
    await settle(tester, 3);
    expect(find.text('History'), findsOneWidget);

    await tab(tester, Icons.event_note_outlined);
    await openAndBack(tester, find.text('Apply Leave'));

    await tab(tester, Icons.receipt_long_outlined);
    await openAndBack(tester, find.text('Net pay').first);

    await tab(tester, Icons.grid_view_outlined);
    await openAndBack(tester, find.text('Holiday calendar'));

    await openAndBack(tester, find.text('My profile'));
    expect(find.text('Admin / HR'), findsNothing);

    await tester.pumpWidget(const SizedBox());
  });
